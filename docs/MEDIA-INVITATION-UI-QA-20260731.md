# 媒体邀请客户界面 QA（2026-07-31）

验收范围：本机 Docker 演示环境中的客户侧 `/media-invitation`；本记录不证明外部媒体、记者资料或媒体履约已经接通。

## 已核验的产品边界

- 客户从“邀请媒体”进入单一媒体邀请页，不再展示“按媒体筛选”“按记者筛选”两张并列入口卡；
- 已启用并通过验收的资料库场景中，操作顺序固定为先筛选媒体、再在已选媒体内筛选记者；
- 当前本机没有可验收的外部媒体/记者连接，客户页如实显示“在线筛选暂不可用，可人工补充候选名单，由项目负责人核验。”，并仅保留人工补充拟邀对象的入口；
- 人工补充只形成待核验的拟邀名单。保存计划不自动向媒体发出邀请，也不表示媒体到场、采访或报道；
- 客户页不显示供应商、成本、上游接口、令牌或内部配置。

本测试不创建项目、名单、计划、任务、订单或外部请求；客户登录可能保留正常会话或审计记录。

## 仍待正式验收的门槛

牛媒或其他外部媒体/记者数据的授权、范围、运行凭据、限流、超时、逐家接口联调及验收证据尚未作为本机演示环境的输入。在这些材料齐备前，不得把筛选页、人工补充或内部配置写成实时媒体资料或真实邀约履约能力。
