## 业务边界

- 云采写：客户下单，平台优先匹配当地专业写手完成现场素材采集、稿件撰写和约定修改。
- 媒体公关：确认邀请范围、联系媒体与记者并协调现场。
- 写手不负责媒体邀请，也不决定媒体是否发布。
- 媒体是否到场、采访、报道和发布，由媒体独立决定。
- 云采写参考价：980 元 / 人 / 天；差旅、时长与交付范围在下单前确认。
- 云采写是可独立下单、也可嵌入传播项目的服务模块，不设置为一级频道。
- 发布计划先保存并由客户确认；确认前不生成发布任务。
- 客户界面和客户 API 不显示供应商、原始来源、成本价或内部备注。

## 数据说明

- 资源数量必须由当前运行数据库实时统计；设计稿不把历史导入数量写成当前在线承诺。
- 对客页面只展示可核验、当前可用的资源口径，不展示供应商来源。
- Dashboard 用于呈现产品状态与项目计数，不冒充客户案例；执行记录随项目进度更新。
- 媒体资源区使用“推荐范围”，价格和可用状态以下单前确认为准。
