# 媒体邀请案例公开边界

最后更新：2026-07-31

## 结论

`/cases/industry-forum` 现仅作为“媒体邀请项目（脱敏样本）”的公开边界说明页。它不再是项目复盘页，也不展示任何操作过程、工作步骤、材料目录、现场图片、名单或结果。

该页面只证明：媒体邀请可以作为独立服务纳入项目记录。它不证明任何媒体被筛选、接触、邀请、回复、到场、采访、报道或发布。

## 允许公开的信息

- 服务类别：媒体邀请；
- 展示目的：说明项目摘要与公开边界；
- 原始资料状态：不公开；
- 未取得书面授权前，实名案例和成果不发布。

## 禁止公开的信息

- 项目、客户、活动、行业、地点、日期、人员、机构与媒体身份；
- 媒体筛选条件、候选名单、联系人、邀约节奏、沟通记录与执行日志；
- 方案、提纲、手册、稿件、汇报、附件、原图、现场图片、报价、费用与结果数据；
- 未经书面授权的案例归因、传播数量、履约结论或商业效果。

## 技术处理

- 页面已删除“执行过程”“现场资料”“项目成果”等内容模块；
- `frontend/public/case-media/` 中原用于该案例的 7 个现场展示衍生图已移除，旧 URL 返回 HTTP 404；
- 页面不加载 `/case-media/` 图片，不提供原件、图片、名单或办公文档下载；
- 路由继续使用 `noindex, nofollow, noarchive, nosnippet`，`robots.txt` 禁止抓取案例及素材命名空间；
- `/case-materials/` 继续固定返回 HTTP 404。

搜索引擎指令不是访问控制。真正的保护来自不向公开镜像部署文件、不把操作数据写入前端包，以及仅在经权限控制的项目内保留敏感资料。
