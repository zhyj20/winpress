# 三类角色操作菜单与路由 QA（2026-07-31）

验收范围：本机 Docker 演示环境；本记录不替代生产账号、外部数据或履约验收。

## 发现

有效 PRD 第 4 节规定，客户侧服务下单入口应使用“举办新闻发布会”。当前 `AppShell.vue` 虽然已链接到正确的 `/requirements/news-conference` 页面，但菜单仍显示“新闻发布会”，与产品服务名称不一致。

同时，既有浏览器回归覆盖了部分客户和管理页面，却没有把三类角色的菜单分组、顺序、路由与移动端操作菜单作为一个固定验收项。此类偏差不会阻断后端下单，却会增加客户理解成本并可能在后续页面调整中再次出现。

## 修复

- 客户侧菜单名称统一为“举办新闻发布会”，路由保持 `/requirements/news-conference`；
- 新增 Playwright 三角色菜单回归：客户、服务运营、平台运营分别校验菜单分组、项目顺序、路由和当前角色标识；
- 移动视口先打开“操作菜单”再核对侧栏；客户侧另实际点击“举办新闻发布会”，确认进入对应页面并显示主标题。

测试账号仅由本机测试文档或环境变量读取，测试输出不打印账号、密码、令牌或响应正文。
