# 外部接入与上线验收关卡

## 当前实现

管理员账号新增“接口管理”页面，分为：

1. 接口配置：供应商、用途、环境、鉴权、接口路径、限流、超时、重试、数据范围和凭据环境变量名称；
2. 上线验收：外部媒体数据、供应商真实履约、法律与信任、生产运维、历史组合服务五项关卡及其 28 项必备证据；
3. 历史组合审核：逐条记录 `WRITING_AND_PUBLISHING` 的业务决定，不执行自动迁移。

数据库约束保证：

- 授权标记为已核验时必须登记合同和证据；
- 沙箱标记为通过时必须登记证据；
- 生产标记为批准时必须登记证据；
- 授权、沙箱、生产批准和对应逐项证据未齐备时不能启用接口；
- 外部媒体关卡还要求存在满足数据范围、检索路径和限流要求的已验收生产连接；
- 供应商真实履约关卡还要求存在具备下单、状态、回调、对账和服务等级配置的已验收生产连接；
- 供应商订单未写明人工/API 履约方式及提交凭据时不能进入“已提交”及之后状态；
- 历史组合记录批准处理方案时必须登记明确动作和业务确认凭据。
- 新请求不能创建 `WRITING_AND_PUBLISHING`；存量记录未经已批准的逐条决定不能转换服务类型。

## 当前状态

下列事项仍保持“待验收”，不能写成已接通或已上线：

- 牛媒及其他外部媒体数据的正式授权、数据范围、令牌、限流和联调；
- 逐家供应商的真实报价、下单、回执、对账、异常重试和服务等级；
- 经营主体、备案、地址、客服、隐私、条款、案例授权和生产域名；
- 隔离预发布环境的生产冷启动、备份恢复、TLS、域名、监控告警和迁移演练；
- 历史组合服务的逐条业务映射决定。

本机界面在这些关卡通过前继续提供人工补充与人工核验路径。管理员界面显示逐项证据完成度，但“录入配置”或“创建内部订单”均不等于外部数据、真实下单或履约已接通。
