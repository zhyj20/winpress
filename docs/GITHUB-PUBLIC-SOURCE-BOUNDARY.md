# GitHub 公开源码边界

本仓库用于代码同步、审查和可复现的开发环境，不是生产数据、客户资料或供应商履约资料的分发渠道。

## 可以公开

- 前后端源码、数据库结构、迁移、测试与部署模板；
- 无真实凭据的 `.env.example`；
- 经过公开审核、压缩处理并已用于站点展示的案例派生图；
- 仅含表头的媒体导入样例，用于验证数据库导入结构。

## 不会提交

- 媒体目录、报价、供应商成本、供应商回执和外部接口令牌；
- 客户合同、原始采访材料、可下载的案例原件及本机上传文件；
- 测试账号清单、会话、运行日志、数据库备份与本机验收工件；
- 生产 `.env`、域名证书、私钥、OAuth 或 API 凭据。

## 本机受控数据

如已取得数据授权，可在本机从 `.env.example` 创建 `.env`，通过以下两个变量挂载批准的数据文件：

```dotenv
WINPRESS_MEDIA_CHANNELS_CSV=./private-data/media_channels.csv
WINPRESS_MEDIA_QUOTES_CSV=./private-data/media_quotes.csv
```

这两个路径只用于本机开发或隔离预发布。它们必须位于受控存储中，不得进入 Git、静态资源目录或客户可访问的接口。外部数据未完成授权、字段审查、令牌配置、限流策略和联调验收前，客户页面只能提供人工补充路径，不能声称实时媒体或记者数据已经接通。

公开源码的 `scripts/verify-clean-local-db.ps1` 与 `scripts/verify-cold-start.ps1` 会优先使用显式参数或以上环境变量；没有受控输入时退回到仅含表头的公开样例，并明确输出 `PUBLIC_HEADERS_ONLY`。该模式只验证数据库结构、导入路径和迁移完整性，既不含媒体目录或报价，也不验证本机账号密码。受控输入只证明本地文件一致性，不构成外部数据授权、实时检索或真实履约验收。
