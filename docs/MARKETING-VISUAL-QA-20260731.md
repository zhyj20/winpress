# 营销页视觉优化与回归记录（2026-07-31）

## 本轮目标

将首页从浅色、大卡片、低对比和偏小正文的展示状态，收束为更适合企业新闻传播产品的阅读层级：主色更集中，信息更紧凑，正文与操作入口更易读。

## 已实施

- 首页采用深蓝、青绿与暖橙的有限色板；强调状态、服务入口和行动区，而非给每张卡片附加无意义的装饰；
- 正文提高到桌面端 `19px`、移动端 `16px` 的可读尺度，并提高行距；
- 四项独立服务入口、渠道卡、案例卡和资讯卡减少无效留白与最小高度；
- 移动端新闻流改为两列阶段卡，避免单列串联造成页面过长；
- 保持业务边界：云采写、媒体邀请、直编发稿、新闻发布会仍为独立服务，未恢复错误的首页记者匹配承诺，也未把未验收外部接口包装为实时能力。

## 回归证据

| 视口 | 结果 |
| --- | --- |
| 1440 × 900 | 无水平溢出；首屏正文 19px；四项入口卡高度 286px。 |
| 768 × 1024 | 无水平溢出；入口卡两列排列。 |
| 390 × 844 | 无水平溢出；正文 16px；新闻流两列压缩展示。 |

同轮验证已通过：前端类型与格式检查、前端生产构建、后端 Maven `verify`（172 项测试）和 Playwright 多视口回归（108 项）。该记录只证明当前本机版本的视觉与工程回归；不替代外部数据、供应商履约、法律文本或生产环境验收。
