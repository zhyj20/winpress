# Historical report catalogue — 2026-07-31

## Purpose

This catalogue records the classification of user-supplied historical communication reports for the WinPress case directory. It is an internal traceability record, not a public case authorization, results statement, or source-file index.

The client build receives only a safe catalogue: project title, time period, report type and a limited “link record” count when the source itself contains that count. It never receives source paths, original files, media lists, URLs, prices, costs, contacts, quotations or supplier details.

## Classification rule

| Category | Inclusion test | Product boundary |
| --- | --- | --- |
| 新闻发布会与活动传播 | The source relates to a signing ceremony, conference, launch event, customer day, exhibition, or its event-stage communication record. | This is an event-project archive label. It does not promise independent media attendance, interviews or coverage. |
| 直编发稿 | The source records a confirmed article being published through specific media/channel fields, usually marked `直发`, `转载`, `官网`, publication date and link. | This records historical publication entries, not current channel availability, current pricing or future delivery. |

“链接记录” is a count of link entries in the supplied report, not a claim that every historical URL remains live or that the result may be used as marketing proof.
