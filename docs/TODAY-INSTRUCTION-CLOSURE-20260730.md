## 不得误判为已完成的事项

- 静态种子库有 `22,364` 个渠道，只证明本地数据文件及导入链路完整，不证明当前媒体授权、价格时效、记者数据或可发布性。
- 管理员可以登记接口，不证明任何供应商已经真实接单、回执或对账。
- 隔离生产等价环境通过，不等于正式域名、TLS、监控、备份恢复和生产数据库迁移已经验收。
- 法律、联系与案例页面具备发布结构，不代表主体资料、案例授权和政策文本已获权利方确认。

## 外部输入到齐后的执行顺序

1. 权利主体确认法律、联系、备案、案例授权和生产域名。
2. 供应商逐家提交合同、字段映射、沙箱账号、限流、回调、对账及 SLA 证据。
3. 管理员在“接口管理”登记凭据环境变量名称和验收材料，不把令牌写入数据库。
4. 在隔离预发布环境完成真实检索、下单、回执、超时、重试、TLS、监控和恢复演练。
5. 五项上线关卡分别复核；只有证据齐全的能力才可启用或改为客户可见。
