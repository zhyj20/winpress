# 牛媒媒体与记者检索接入说明

## 接口依据与联调结论

本仓库以媒体资料库调用文档为适配依据，保留服务端媒体与记者检索接口，供媒体邀请和新闻发布会的“先媒体、后记者”流程使用。

当前本机验收环境未提供可验证的正式授权、数据使用范围、生产限额或供应商履约确认。因此检索与筛选字典在未配置授权时必须显示为“待配置 / 不可用”；不得以导入数据、缓存、演示结果或历史接口响应替代实时能力，也不得向客户表示已接通外部媒体资料库。

## 返回结构兼容

调用文档示例使用：

- 媒体：`data.count`、`data.results`
- 记者：`data.count`、`data.results`

调用文档及适配器兼容的另一组可能返回结构包括：

- 媒体：`data.page_total`、`data.page_index`、`data.page_size`、`data.media_list`
- 记者：`data.page_total`、`data.page_index`、`data.page_size`、`data.reporters`

适配层在服务端兼容已授权资料库的返回结构。浏览器只接收对客筛选所需的公开字段：短时 `candidateKey`、候选类型、显示名称、记者名称、媒体属性、省市、媒体形态、行业标签及有限的公开画像字段。

上游媒体编号、记者编号、供应商处理备注、原始价格、令牌和上游原始响应均不进入浏览器。候选引用与登录用户、组织和有效期绑定；服务器在写入项目候选时解析引用，跨组织、过期或伪造引用必须被拒绝。

## 云发布中的两个用途

### 媒体邀请

客户在“媒体邀请”页先按议题、领域、线口、省市、媒体属性和渠道形态筛选媒体。选中某家媒体后，系统只携带该候选的短时 `media_ref` 查询其记者或编辑；客户从记者名单中建立拟邀对象，再统一创建邀请计划。媒体与记者不再作为两个并列入口。

媒体邀请不要求先有定稿；当前客户入口只用于建立拟邀名单并提交项目核验，不提供线上排他条款或稿件锁定下单。另行约定的既有安排由项目负责人依约处理。

资料库尚未验收或暂不可用时，客户仍可人工补充媒体或记者名称建立拟邀计划。该名单只进入“待项目核验”队列，不借用静态渠道作为执行渠道，不自动发出邀请，不生成供应商订单、价格或“媒体已确认”状态。

### 新闻发布会媒体筛选

发布会项目使用同一检索能力建立项目拟邀名单。用户可以批量勾选候选并一次加入项目；候选随后按“候选、待邀约确认、已邀请、已回复、到场、拒绝、不再推进”管理。

拟邀名单仅用于项目执行，不能表达为到场、采访或报道承诺。

## 服务端配置

```text
WINPRESS_NIUMEDIA_BASE_URL=https://api.media.beer/v1
WINPRESS_NIUMEDIA_TOKEN=
WINPRESS_NIUMEDIA_MEDIA_SEARCH_PATH=/media/search
WINPRESS_NIUMEDIA_REPORTER_SEARCH_PATH=/reporter/search
WINPRESS_NIUMEDIA_REGION_PATH=/region
WINPRESS_NIUMEDIA_MEDIA_TYPES_PATH=/media/types
WINPRESS_NIUMEDIA_MEDIA_FORMS_PATH=/media/mp_types
WINPRESS_NIUMEDIA_REQUEST_TIMEOUT_SECONDS=15
WINPRESS_NIUMEDIA_SEARCH_CACHE_SECONDS=300
WINPRESS_NIUMEDIA_TAXONOMY_CACHE_SECONDS=86400
```

正式令牌只能放在后端环境变量或密钥管理系统中，禁止写入源码、`VITE_*` 变量、Cookie、接口响应和日志。收到正式授权后，应在隔离环境复测授权失败、额度、并发、缓存期限、字段范围和数据使用边界。

## 缓存与降级

- 相同检索条件默认缓存 300 秒，避免重复消耗搜索额度；
- 省市、媒体属性和媒体形态默认缓存 24 小时；
- 实时请求失败但存在最近一次成功结果时，返回缓存并标记 `stale=true`；
- 无缓存可用时，界面保留人工补充拟邀媒体的入口；人工名单仅能进入待项目核验，不自动绑定渠道或执行邀请；
- 不关闭 TLS 校验，不使用测试地址的错误证书，不伪造实时结果。

## 上线前验收

1. 由数据权利方确认正式授权、字段范围、地域和行业使用限制、有效期、限额及数据处理要求。
2. 在隔离环境完成媒体检索、媒体后记者检索、超时、限流、授权失败、缓存失效和人工补充流程的联调，并保留不含敏感信息的验收记录。
3. 复核客户、项目运营和平台运营三类角色的候选范围；确认客户响应不含外部编号、供应商、成本、令牌或内部备注。
4. 取得供应商联动、价格口径、回执和服务等级的独立验收后，才可在对客页面声明外部履约能力。

在以上条件完成前，本文件仅说明代码预留的接入边界，不构成外部数据、媒体资源、供应商服务或生产可用性的承诺。
