# 关于我们页面：公开资料核验记录

更新日期：2026-07-31  
适用页面：`frontend/src/views/AboutView.vue`

## 使用目的

本记录为“关于我们”页面的业务沿革提供可追溯的公开资料依据。页面只保留与云发布业务有关的工作演变，不把客户关系、供应商信息、未授权案例、生产数据或个人隐私写入客户页面。

- 广州麦媒信息科技有限公司与闻客信息（深圳）有限公司之间的法律主体、股权、品牌授权或业务承继关系，尚未由权利主体提供本轮生产发布确认；页面不得据此作法律连续性声明。
- 公司主体、备案号、地址、客服电话、资质、奖项、客户名称、案例结果和生产域名必须另行完成权利与事实核验后，才可发布。
- 牛媒或其他外部媒体数据的授权范围、令牌、限流与接口验收未完成前，云发布客户页面不得宣称已经接通实时媒体或记者数据。
- 任何历史报道、访谈观点或第三方项目资料均不能替代云发布的服务范围、价格、排期、媒体到场、报道或发布结果承诺。
