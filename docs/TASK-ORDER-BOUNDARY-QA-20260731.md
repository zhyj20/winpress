# 任务记录与订单管理边界 QA（2026-07-31）

验收范围：本机 Docker 演示环境中客户侧的 `/orders` 与 `/order-management`。本记录只说明页面、接口投影与权限检查结果，不代表真实供应商、支付、收款、退款、媒体履约或生产账务已经验收。

## PRD 对齐

- `待办事项`只保留当前需要处理或确认的事项；
- `媒体与发布任务`保留媒体邀请与直编发稿的当前执行任务；
- `任务记录`只呈现四项独立服务已发生的任务，不再在同一页重复项目台账、项目清单或项目汇总请求；
- `订单管理`保留服务订单、交易记录与结算记录，并按云采写、媒体邀请、直编发稿、举办新闻发布会四类服务筛选；
- 项目仍由独立的“项目管理”入口承载，任务记录页只保留一个跳转入口，避免项目和任务两套清单互相覆盖。

## 本轮修复

1. 移除任务记录页的项目台账卡片和项目清单，删除不再需要的项目汇总请求；
2. 在任务明细标题区保留“项目管理”和“查看当前待办”两个明确动作；
3. 将服务筛选、项目筛选和营销模块中的正式服务名称统一为“举办新闻发布会”，消除同一服务在不同页面显示为“新闻发布会”的漂移；
4. 新增 Playwright 回归，固定检查任务记录不再出现项目台账/项目清单，订单管理仍具备四类服务筛选，且客户页面不出现供应商成本或上游接口字段。
