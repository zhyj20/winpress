## 业务回归

- 日常下单只保留媒体邀约、云采写、直编发稿和举办新闻发布会四项服务。
- `现场采写 + 媒体邀请` 组合卡片已删除；采写、邀请和发稿按需分别下单。
- API 接入不进入日常服务选择，仅保留独立说明页。
- 新闻发布会订单只强制填写需求标题、会务联系人和联系电话，其余资料允许后补。
- 现场采写只创建云采写任务，不创建媒体邀请或发布承诺。
- 媒体邀请与直编发稿继续使用各自的资源、价格和执行规则。
- 媒体邀请支持媒体与记者双入口筛选、批量选中、保存计划、确认计划和任务生成。
- 发布会工作台支持媒体与记者候选批量加入；重复候选由唯一索引拦截。
