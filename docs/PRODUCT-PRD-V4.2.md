# 云发布产品需求文档 V4.2

版本日期：2026-07-28  
适用源码：`.winpress-media-integration-20260726`

## 1. 产品定义

云发布是企业新闻传播项目的操作执行系统。平台管理四项可独立下单的服务，并在项目中统一呈现进度、资料、任务、费用和成果：

1. 云采写；
2. 媒体邀请；
3. 直编发稿；
4. 新闻发布会。

API 接入属于商务与技术合作，不是第五种日常订单。客户须先联系客服，由平台确认授权、字段、价格、额度、联调与验收方案。

## 2. 不做什么

- 不以“记者接有偿写稿”方式交付云采写；
- 不承诺媒体到场、采访、采用、报道或收录；
- 不把云采写和媒体邀请包装成组合订单；
- 不在云发布管理客户自有渠道或 GEO 治理工作；
- 不向客户公开供应商、内部成本、上游接口或运营备注；
- 不用演示数据、未授权品牌或模拟指标冒充客户案例。

## 3. 服务模型

### 3.1 云采写

- 客户提交活动、地点、时间、天数、人数和稿件要求；
- 基础价为 980 元/人/天；
- 平台按地点、档期和服务范围匹配写手；
- 写手负责素材采集、资料梳理、稿件撰写和修改；
- 媒体邀请和发布另行下单。

### 3.2 媒体邀请

主流程：

1. 按议题、领域、线口、地区和媒体属性筛选媒体；
2. 选中媒体后查询该机构记者或编辑；
3. 建立拟邀名单；
4. 绑定项目并保存邀请计划；
5. 客户确认后生成任务；
6. 项目专员仅在实际发生后记录已发出邀请、回复、到场及采访等执行事实；如形成报道成果，须提交可核验链接后才登记完成。

媒体邀请计划只能绑定媒体邀请项目，不能借用发布会或其他服务项目生成任务。客户不得查看未授权私人联系方式。媒体是否参与或报道由媒体自主决定；客户侧不把任务创建、项目异常或计划保存表述为已邀请、已回复或已报道。

### 3.3 直编发稿

主流程：

1. 选择已有定稿的项目；
2. 按地区、分类、发布形式、价格和时效筛选渠道；
3. 批量选择渠道并查看客户服务价；
4. 保存发稿计划；
5. 客户再次确认；
6. 系统生成渠道任务和受控的内部履约记录；实际对外提交须在稿件、渠道、价格和排期核验后另行登记；
7. 平台复核稿件、栏目、排期和发布结果。

发稿计划只能绑定直编发稿项目。对客展示的当前计划价仅供项目核验前的预算与确认参考，不等同于已向外部渠道确认的最终价格、库存或排期。对客只展示客户服务价和公开条款；成本价、供应商、外部产品编码和内部异常仅平台管理员可见。

### 3.4 新闻发布会

首次提交只强制填写：

1. 需求标题；
2. 会务联系人；
3. 联系电话。

同页可补充活动信息并筛选媒体/记者。项目建立后自动生成会前、现场、会后九项执行清单；云采写、媒体邀请和直编发稿仍分别确认、计价和执行。

## 4. 客户信息架构

“品牌工作台”是客户空间名称，不是与业务页面并列的菜单。客户菜单按工作顺序分为：

1. 项目总览：传播看板、项目管理；
2. 服务下单：提交需求、云采写、邀请媒体、直编发稿、举办新闻发布会；
3. 任务与订单：待办事项、媒体与发布任务、任务记录、订单管理。

账号信息、当前用户、角色和退出登录放在侧栏底部同一区域。

后续应继续收敛“任务管理、任务记录、订单管理”的职责：

- 待办事项：当前需要客户处理或确认的事项；
- 媒体与发布任务：媒体邀请与直编发稿的当前执行任务；
- 任务记录：已发生的全部服务任务；
- 订单管理：四项服务订单、结算单，以及有凭据的收款、退款、贷项、借项和核销记录。

结算状态和交易事实必须分开：管理员不能通过把结算单改成“已结清”来制造收款；每笔交易至少要有凭据编号或客户可见说明。客户只能查看本组织项目的公开交易字段，平台内部备注、登记人、作废人和作废原因不对客返回。

## 5. 平台运营能力

- 渠道管理；
- 客户价、成本价和毛利管理；
- 单渠道人工调价和批量比例调价；
- 多渠道比价；
- 供应商资料与渠道关系；
- 供应商订单与异常处理；
- 咨询与 API 接入申请；
- 结算、用户、权限和审计。

多供应商实时 API 尚未完成生产验收。现阶段必须区分：

- 数据库中的已导入报价；
- 人工维护报价；
- 外部 API 实时报价。

## 6. 看板口径

建议统一为：

- 需要我处理；
- 进行中的项目；
- 待客户确认；
- 待平台执行；
- 已完成待验收；
- 已核验来源的外部工单（仅有权限的运营人员）。

每个数字必须与点击后的列表使用同一查询条件。后端字段缺失时显示“数据暂不可用”，不得回退为 0。

只有记录具备可核验的来源标识时，页面才可使用“牛媒信源工单”名称；现有商务咨询没有来源字段时，应统一显示“商务咨询”，不得根据客户名称或对话背景推断来源。

## 7. 数据与外部接口

### 7.1 牛媒数据

- 服务器端持有 Token，浏览器不得直连或保存上游凭据；
- 媒体查询后才能按 `media_id` 查询记者；
- 领域/线口为业务筛选字典，省/市、媒体属性和渠道形态优先使用正式接口数据；
- 上游超时可显示缓存结果，但必须标明更新时间；
- 正式上线前验收端点、额度、许可、缓存期限和删除义务。
- 未完成上述验收时，客户页面只能显示“暂不可用”或人工补充路径；本机静态渠道与报价文件仅用于受控回归，不能自动导入生产、不能替代正式授权，也不能表述为实时可履约媒体资源。
- 生产环境如需启用外部目录，须另行完成来源与许可、对客字段、价格有效期、备份点和书面上线批准的核验；未经核验的目录不得让客户在线选择。
- 客户人工补充的媒体或记者名单可以保存为媒体邀请计划，但只能标记为“待项目核验”。保存计划不等于已发出邀请、已建立供应商订单、已有报价或媒体已确认参与；只有项目核验完成并由获授权人员实际联系后，才可记录相应事实状态。

### 7.2 GEO 客户 API

- 客户 API 只返回许可字段和客户价格；
- 请求须鉴权、幂等、审计和限流；
- 不返回供应商、成本价、上游 Token、内部订单或运营备注；
- 联邦订单必须携带租户、组织、品牌、项目和订单标识；
- 正式凭据、回调地址和验收报告由双方联调后确认。

## 8. 商用发布门槛

### 代码与数据

- Vue 生产构建通过；
- Java 测试通过；
- 空库可以从源码重建；
- 本机受控静态媒体渠道和报价种子具有行数与 SHA-256；该完整性校验不等于外部数据授权、实时查询或供应商履约验收；
- 三种角色权限回归通过；
- 客户接口无成本和供应商泄漏。

### 外部条件

- 牛媒正式授权、额度和许可；
- 公司主体、备案、客服与办公信息；
- 隐私政策和服务协议法务复核；
- 案例授权及证据；
- 生产域名、TLS、备份和监控。

外部条件未满足时，文档和页面必须写“待确认”，不得写成已上线能力。
