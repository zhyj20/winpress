## 数据与产品边界

1. 高级目录属性来自当前静态目录中已经存在的确定标签，是本机目录分析与预算参考，不是实时库存、发稿承诺或上游授权证明。
2. 本轮未新增数据库迁移。结构版本保持 `33`；高级属性仍应在取得数据权利、完成字段定义和迁移方案后转为独立结构化列，不能长期依赖备注解析。
3. 方法论与案例页面没有引用未经授权的客户名称、传播数量或结果。案例只描述可执行工作流。
4. `.ics` 文件不会带出客户联系电话、内部负责人、供应商、成本、令牌、密钥或内部说明。
5. 未恢复 `WRITING_AND_PUBLISHING` 新下单能力，也未把 API 接入放回普通服务下单；历史组合记录继续保留为只读档案。
