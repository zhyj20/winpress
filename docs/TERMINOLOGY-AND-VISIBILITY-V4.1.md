# 云发布术语与数据可见性 V4.1

> 历史术语记录（非当前验收基准）。当前客户可见性、四项独立服务和外部能力待确认规则以 [`PRODUCT-PRD-V4.2.md`](PRODUCT-PRD-V4.2.md) 与 [`WINPRESS-GLOBAL-PRODUCT-CODE-AUDIT-20260728.md`](WINPRESS-GLOBAL-PRODUCT-CODE-AUDIT-20260728.md) 为准。

## 1. 统一术语

| 对外名称 | 内部代码 | 定义 | 不应混用 |
|---|---|---|---|
| 云采写 | `ONSITE_WRITING` | 平台写手完成现场或远程事实素材采集、撰写与修改 | 媒体记者采访、媒体邀请、保证发稿 |
| 媒体邀请 | `MEDIA_INVITATION` / 兼容 `MEDIA_PR` | 向媒体或记者发出活动、采访或报道邀请并记录反馈 | 直编渠道购买 |
| 直编发稿 | `DIRECT_PUBLISHING` | 已有定稿后购买明确渠道服务 | 编辑部自主选题报道 |
| 新闻发布会 | `NEWS_CONFERENCE` | 围绕一次重要活动管理议题、会务、媒体和会后传播 | 单一发布渠道 |
| API 接入咨询 | 非普通订单类型 | 评估客户系统的媒体清单、价格规则、下单与回传接口 | 日常服务下单、KPI、GEO 主平台 |
| 发布计划 | `publish_plan` | 客户确认前的渠道、预算、稿件与规则快照 | 发布任务、订单 |
| 发布任务 | `publish_task` | 发布计划确认后拆分的执行单元 | 计划草稿 |

## 2. 数据可见性矩阵

| 字段或对象 | 客户 | 写手/服务运营 | 平台运营 |
|---|---:|---:|---:|
| 客户服务价 | 是 | 按任务需要 | 是 |
| 成本价、毛利 | 否 | 否 | 是 |
| 供应商、来源平台 | 否 | 直编执行且有权限时 | 是 |
| 记者/编辑联系人 | 仅显示经确认的公开状态 | 媒体邀请任务需要时 | 是 |
| 原始 API 载荷、密钥 | 否 | 否 | 仅系统配置角色 |
| 稿件与版本 | 自己项目 | 被分配项目 | 是 |
| 写手档期与服务范围 | 仅显示匹配结果 | 自己 | 是 |
| 写手手机号、证件与结算资料 | 否 | 自己 | 授权运营与财务 |
| 项目执行状态 | 是 | 被分配项目 | 是 |
| 操作审计 | 自己的关键确认记录 | 自己任务 | 是 |

## 3. 客户接口输出规则

客户渠道接口允许返回：媒体或渠道名称、公开分类、地区、发布形式、预计时效、客户服务价、有效期、公开规则和当前可用状态。

客户接口禁止返回：`providerName`、`sourceType`、`sourceRef`、`costPrice`、内部采购备注、接口账号、密钥和原始错误信息。

如合同确实要求披露承接主体，应通过单独的合同字段和权限开关返回，不得直接复用内部供应商字段。

## 4. 案例规则

- 真实品牌名称只有在获得对外授权并保存证据后才能使用。
- 没有授权时使用匿名行业描述，例如“某上市芯片企业”。
- 产品演示数据必须标记“产品演示”，不得使用“客户案例”“客户成果”等表述。
- 案例只陈述可核验的背景、动作和交付，不伪造媒体数量、阅读量、金额和效果。
