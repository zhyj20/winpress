# 云发布领先产品持续审查目标提示词

以《云发布 WinPress 全局产品与代码审查》、有效 PRD、当前源码、当前数据库和可复现验收证据为唯一事实基础，持续把云发布建设为企业新闻传播项目操作执行系统。不要从零重做产品，不恢复已否决的组合服务、记者匹配写手、普通 API 自助下单或客户侧供应商管理。

## 产品目标

四项服务——云采写、媒体邀请、直编发稿、新闻发布会——必须保持独立下单、独立项目、独立任务、独立计价和独立验收；同一活动下只做关联查看，不合并业务记录。客户必须能在自身权限内查看需求、项目、待办、任务、订单、稿件版本、媒体名单、进度与已核验结果。

云采写按平台写手服务建设。现场采写基础价为 980 元/人/天，写手负责资料整理、现场采集、撰写和修改，不以媒体记者身份承接，不负责媒体邀请，不决定报道或发布。媒体邀请从媒体筛选进入所选媒体的记者筛选；媒体是否到场、采访或报道由媒体独立决定。直编发稿必须绑定客户定稿和有效报价。新闻发布会负责活动清单与现场统筹，采写、媒体邀请和直编发稿仍分别下单。

## 审查顺序

每轮先审计，后修复。按 P0、P1、P2 顺序处理：

1. P0：登录、权限隔离、下单、幂等、项目生成、任务协同、订单计价、客户数据边界、数据库约束、部署一致性。
2. P1：错误和空状态、渐进式表单、搜索筛选、移动端操作、超时重试、供应商订单、结算台账、接口验收与审计追踪。
3. P2：营销内容、案例证据、方法论、内容栏目、性能、可访问性与持续维护体验。

发现问题时必须说明：问题、根因、影响、修改、验证证据、回退边界和仍待外部确认的事项。不能用“已优化”“已接通”“可上线”等结论代替证据。

## 数据与接口边界

客户页面只显示完成服务所必需且可核验的信息。供应商名称与联系方式、成本价、上游订单、接口地址、令牌、密钥、内部规则、重试策略和运营备注不得出现在客户接口或页面。

牛媒及其他外部媒体数据在取得正式授权、确认数据范围、配置受控凭据、确定限流策略并完成联调验收前，只能显示“暂不可用”和人工补充路径。运行环境里存在令牌不等于取得授权，也不等于联调通过。

外部供应商只有在合同、字段映射、沙箱、真实下单、报价、回执、对账、超时、重试、异常处理和服务等级均有验收记录后，才能标记为可用。平台内部的供应商和订单管理能力，不得写成已经接通真实履约。

接口配置只保存凭据环境变量名称，不保存或回显令牌明文。禁止提供可由管理员任意输入地址并立即发起请求的通用“测试连接”功能；外部请求必须由经过审查的专用适配器执行，并有地址白名单、超时、限流、审计和脱敏日志。

## 商用与生产边界

公司主体、备案、地址、电话、邮箱、法律文本、案例授权和生产域名必须由权利主体提供材料并核验后发布。未核验信息在对客页面隐藏，在管理员验收台账中显示待办，不能用演示资料替代。

生产发布前必须在隔离预发布环境完成：数据库迁移、备份恢复、最小权限网络、生产冷启动、TLS、域名切换、监控告警、日志脱敏、容量和故障恢复验证。本机绿色检查只证明本机基线，不等于生产验收。

历史 `WRITING_AND_PUBLISHING` 记录只进入人工审核台账。先形成逐条映射清单和业务确认凭据，再编制独立迁移；禁止自动拆单、改价、删除或归档。

## UI 与文案

页面标题优先使用准确的名词或动名词词组；解释性长句放在小号备注中。删除空泛口号、同义反复、开发解释和“赋能、闭环、重塑、智能推荐最佳”等无证据表达。每页先回答“这是什么、能做什么、下一步在哪里”，再展示细节。

导航名称、顺序和目标页面必须与角色任务一致。表单只把履约必须字段设为必填；发布会首次提交只强制标题、联系人和联系电话。桌面、平板和移动端均须保证无横向溢出、按钮可触控、表格可操作、错误可恢复。

## 每轮验收

每次改动至少完成：

- 前端类型检查、格式检查和生产构建；
- 后端全量测试和生产包构建；
- 数据库迁移可重复执行、约束与触发器检查、迁移前备份；
- 客户、运营和管理员权限回归，确认内部字段不外露；
- 四项服务至少各完成一条下单到项目记录的关键路径检查；
- 1440px 桌面端与 390px 移动端页面验证，检查控制台、网络错误和页面溢出；
- 本地 Docker 健康检查、接口合同版本和数据库版本一致性检查；
- 审查报告、迁移说明、源码清单、包校验值和未完成生产关卡更新。

最终报告必须把“已完成并验证”“已实现但未获外部验收”“需要主体方提供材料”“生产环境尚未执行”分开列出。
